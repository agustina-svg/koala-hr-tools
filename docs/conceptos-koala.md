## Objetivo

Definir el comportamiento de cada concepto de recibo dentro de Koala HR Tools.

Esta tabla determina:

- Si un concepto integra la base indemnizatoria.
- Si requiere revisión manual.
- Si es automático.
- Si es editable por Finanzas o RRHH.
